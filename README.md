# Camera Simulator - Optics & Exposure

Interactive simulator to understand camera physics, exposure, and image quality.

## Features
- Real-time aperture, shutter speed, and ISO controls
- Live exposure visualization
- Image quality scoring based on optical physics
- Interactive lens zoom simulation

## Installation

Already done by the PowerShell script! Just run:

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```

Built files will be in the `dist/` folder.

## Technologies Used
- React 18
- Vite
- Tailwind CSS
- Lucide React Icons
